# 星座カメラ (constellation-camera)

夜空の写真から、写っている星座を割り出して重ねて描く Web サービス。

HTML **1 ファイル**（`index.html`, 約 234KB）で完結する。サーバーもビルド済みバンドルの配信も不要で、
ブラウザで開けばそのまま動く。**写真は端末の外に出ない**（このページは一切通信しない）。

- 運営・意思決定の記録は `maedamomo/self-management` の `星座カメラ/README.md` にある。**コードはこちらが正**。

## できること

- 写真に写っている星座の線と名前を重ねて描く
- 星座の一覧（写真に何 % 入っているか付き）
- 主な恒星の日本語名（ベガ、アンタレスなど 211 星）
- 写真をタップすると、その場所の天球座標・近くの星・星座を表示
- 画角（対角何度か）と画面中心の赤経赤緯
- EXIF に撮影日時と GPS があれば、向いていた方角（方位・高度）

## 動かす

```
open index.html          # これだけ。ビルドもサーバーも不要
```

配布するときも `index.html` を 1 枚置くだけでよい。

## 仕組み

中核は**プレートソルビング**（写真に写った星の配置だけから、その写真が天球のどこを向いているかを逆算する処理）。
astrometry.net や ASTAP と同じ発想の簡略版を、依存ライブラリなしで実装している。

1. 写真から点光源を検出する
   （局所背景と局所ノイズの推定 → なだらかなムラの除去 → 星のにじみと同じ幅の整合フィルタ → しきい値処理 → 鋭すぎる／広すぎる成分の除外）
2. 画像上の 2 星の組と、星表の 2 星の組を**仮に**対応させる
3. 「2 点の画素上の位置」と「その 2 星の本当の角距離」から**焦点距離が一意に決まる**
   （焦点距離が大きいほど 2 点のなす角は小さくなる。単調なので逆に解ける）
4. 焦点距離が決まればカメラの向き（回転行列）も決まる。その仮説で他の星がどれだけ合うかを数える
5. 偶然の一致で説明できない数が合ったら採用し、最小二乗で焦点距離・向き・レンズ歪みを微調整する

**画角（ズーム量）が未知でも解ける**のがこの方式の利点。
EXIF に 35mm 換算焦点距離があれば探索範囲を絞れるので、その場合はさらに速い。

偶然の一致を弾くために、採用の条件は仮説ごとに統計的に決めている
（視野内の星表の星数 × 許容円の面積 × 検出点の密度から期待値を出し、それを十分上回ることを要求する）。
視野が広い仮説ほど偶然当たりやすいので、この補正がないと誤答を拾う。

## 構成

```
index.html          単一ファイルの完成品（tools/build.mjs が生成。これを配布する）
src/
  data.js           星表・星座線・日本語名（tools/build-data.mjs が生成）
  astro.js          座標変換・カメラ投影・天球の近傍検索
  detect.js         写真から点光源を検出
  solve.js          プレートソルビング本体
  exif.js           EXIF から焦点距離・日時・GPS を読む
  altaz.js          赤経赤緯 → 方位・高度
  overlay.js        星座線・名前の描画
  sample.js         合成夜空の生成（テストと「サンプルで試す」の両方で使う）
  app.js            画面まわり
tools/
  build-data.mjs    星表データの生成（元データが無ければ取得する）
  build.mjs         src/*.js と template.html から index.html を組み立てる
  template.html     HTML の雛形（スタイルと文言）
test/
  solve.test.mjs       合成画像 18 ケースの検証
  exif-altaz.test.mjs  EXIF 読み取りと地平座標変換の検証
  debug.mjs            失敗ケースの原因切り分け
```

`src/*.js` は素の ES モジュール。ビルドは import/export を落として 1 ファイルに連結するだけで、
バンドラも依存パッケージも使わない。

## ビルドとテスト

```
node tools/build-data.mjs    # 星表データを生成（初回は元データを取得する）
node tools/build.mjs         # index.html を組み立てる
node test/solve.test.mjs     # 合成夜空 18 ケース
node test/exif-altaz.test.mjs
```

Node 18 以降。外部パッケージへの依存はない。

## 精度と限界

| 項目 | 内容 |
| --- | --- |
| 精度 | 合成画像 18 ケースで中心方向のずれは典型 0.001 度 |
| 速度 | 標準的な画角（45〜92 度）なら照合は 5〜100 ミリ秒。画角が想定外だと段階的に範囲を広げるため最大 45 秒 |
| 必要な星の数 | 10 個以上写っていればほぼ確実。6 個未満だと解かない |
| 苦手な条件 | 月が近い / 厚い雲 / 強い街明かり / SNS 圧縮後の画像 |
| 星表の範囲 | 6.0 等まで 5,044 星 |
| 惑星 | 星表に入っていないので識別しない |
| 座標系 | J2000.0（重ね描きは同じ座標系で完結するので歳差の影響を受けない） |

**実際のスマホ写真ではまだ検証していない。** 合成画像は実写に寄せてある
（背景のかぶり・ノイズ・にじみ・飽和・レンズ歪み・周辺減光・日周運動による星の流れ・街灯などの偽の光点）
が、本物の写真で確かめるのが次の作業。

## データの出典

- 恒星: Hipparcos カタログ（6 等まで）
- 星座線・星座名: IAU の定義にもとづく [d3-celestial](https://github.com/ofrohn/d3-celestial) のデータ（BSD-3-Clause）
- 日本語の星名は同データの `ja` フィールドのみを使用。英語名しかない星は表示しない（読みを誤らないため）

`src/data.js` は上記から生成した二次データであり、d3-celestial の BSD-3-Clause 表示を
`index.html` のフッターに記載している。
